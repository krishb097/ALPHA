ALPHA — Modern Digital Agency & SaaS Platform

ALPHA is a sleek, responsive landing page and future SaaS platform crafted for modern web experiences and software solutions. Built with a modern design system, smooth micro-interactions, dark/light theme support, and a dedicated platform roadmap.

✨ Features Implemented (v1.0)

🎨 Design & Aesthetic

- Modern Minimalist UI: Built with Google Font 'Inter' typography and sharp visual contrast.
- Glassmorphic Navigation: Sticky overlay header featuring subtle blur and dynamic link hover animations.
- Pure Dark & Light Mode: Seamless CSS-variable-driven theme engine with zero color mismatches.
- Custom Interactive Cursor: Precision center-dot follower that scales on hoverable elements (with an in-app enable/disable toggle).

📱 Responsive & Mobile-Ready

- Mobile Navigation Drawer: Slide-in navigation menu tailored for tablets and mobile devices with backdrop blur.
- Fluid Layouts: Multi-column grids for About and Services that adapt cleanly down to 320px screens.

⚙️ Preferences & Settings Hub

- Floating Settings Trigger: Fixed bottom-right gear widget with an on-demand popover menu.
- Theme Switcher: Toggles between Dark and Light mode, persisting choices in localStorage.
- Tracker Toggle: Enables or disables the custom follower cursor based on user preference.
- Profile & Admin Portals: Access placeholders ready for authentication and dashboard modules.

💼 Services & Communication

- Featured Service Banner: Highlights Web Design & Development alongside a 6-card modular service grid.
- Contact Form with Validation: Form validation with clean input styles.
- Theme-Adaptive Toast Notifications: Feedback toast alert confirming project inquiries without full-page reloads.

🤖 ALPHA AI (Preview)

- Header AI Trigger: Direct access from the top navbar.
- Modal Preview: Interactive loading spinner modal announcing upcoming features developed specifically for the ALPHA platform.

🛠️ Tech Stack

HTML5: Semantic structure, accessible markup, and optimized metadata.

CSS3: Custom CSS variables, responsive grid/flexbox layouts, CSS animations, and glassmorphism.

Vanilla JavaScript (ES6+): Theme switching, custom cursor physics, modal controller, drawer navigation, and DOM events.

Icons & Fonts: Font Awesome 6, Google Fonts (Inter).
